# 逃离同济大学 · Escape Tongji University

一个单文件网页跑酷游戏。手机、电脑浏览器直接打开即玩。

## 玩法

- 跳跃：空格 / ↑ / 点击屏幕上半部分（空中再点一次是二段跳）
- 滑铲：↓ / S / 按住屏幕下半部分
- 骑龙后：`F` 键或右下角按钮喷火
- 手机：底部「跳 / 滑」按钮，横屏体验更佳

## 特性

- 五个难度，速度、障碍密度、金币倍率、终点距离各不相同（地狱 5000m 终点）
- 3-2-1 开场倒计时 + 校园插画背景，冲过 10000m（按难度）抵达校门终点通关
- 五档翅膀（白羽 / 苍鹰 / 凤凰火 / 星辉 / 神圣龙翼），金币倍率 1/2/3/5/8，可与难度倍率叠加
- 道具：护盾、双倍金币、骑龙喷火、300m 无敌冲刺
- 障碍物：书桌、书架、铅笔、地球仪、纸飞机、海鸥、垃圾桶、护栏
- 存档（金币、最高分、已购翅膀、难度选择）保存在浏览器本地

## 部署

纯静态，无需构建。把仓库开启 GitHub Pages（Settings → Pages → Source 选 main 分支根目录）即可，
访问 `https://<用户名>.github.io/<仓库名>/`。

游戏本体是单个自包含 HTML（图片全部以 base64 内嵌），也可以直接下载 `neon-runner.html` 双击离线玩。
